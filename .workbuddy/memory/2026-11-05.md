## MinGW 链接失败：dbghelp（11-04，用户报 `[337/341] Linking Game.exe` FAILED）

症状：`libVennEngine.a(LuaSelfTest.cpp.obj): undefined reference to
__imp_SymFromAddr` 等 7 个符号，**只有 Game.exe 炸，Editor.exe 正常**。

根因：`engine/script/LuaSelfTest.cpp` 的崩溃处理器用 Sym*/StackWalk64，靠
`#pragma comment(lib, "dbghelp.lib")` 带库 —— **这条只有 MSVC 认**，g++ 静默忽略。

为什么 Editor 不炸（别被它骗了）：`LuaSelfTest.cpp.obj` 在 `libVennEngine.a`
里，静态库只把**被引用**的 obj 拉出来；全仓只有 `runtime/main.cpp`（`--selftest
lua`）调 `runLuaSelfTest` → 链接 Editor 时那个 obj 根本没参与。**"Editor 过了"
不能证明库链全了，只有 Game 会说话。**

修法：`CMakeLists.txt` 的 WIN32 分支加 `dbghelp`（`-ldbghelp` 进命令行），
源文件里的 pragma 用 `#if defined(_MSC_VER)` 包住并注明"两边都得留"。

### 顺带两条工具链教训
- **别在后台把 ninja 管进 `Select-Object -Last N`**：g++ 有 warning 输出时会被
  管道背压卡死，两个 g++ 0% CPU 挂了 27 分钟，kill 后重跑 29 秒就完。
  后台构建一律 `> build/_x.log 2>&1`，再 tail 日志。
- `ScriptRuntime.cpp` 那 10 条 `unknown conversion type character 'z'`
  （`%zu`）是 **MinGW 的误报**：实测 `VK_LOG_INFO("total=%zu", 42)` 打出
  `total=42`。想消掉得把 `Logger.h` 的 `format(printf,2,3)` 在 MinGW 下换成
  `gnu_printf`（会触发全量重编，暂不动）。

## 新建工程没有代码工程 / 没自动开 VS（11-04）

用户原话："创建游戏项目的时候，似乎对应的代码工程没有创建出来并用 VS 自动打开"。

**两个独立的原因叠在一起，缺一都还是"看不见 VS"：**

### ① 选项默认关 + 藏在用户看不到的那一页
`GameCodeGen` 一直能用（`.sln`/`.vcxproj`/`CMakeLists` + msbuild 自检 E1 都在），
但 `LauncherApp::m_wizCpp` **默认 false**，而那个勾选框在**第 2 步（位置）**的
Code 分节底部，"创建"按钮在**第 3 步** —— 用户从来没看见过它。
→ 默认改 true；第 3 步的"将写入"清单里加一行 `code/<Module>.sln（创建后自动
用 VS 打开）`（`describeWrites` 只管 game.json/render.json，列不到它，得自己画）。
新增 `MYVK_LAUNCHER_TEST_NO_IDE=1` 只关"拉起 VS"、不关"生成"，用例才不会被
一排 devenv 拖死。

### ② 勾了也白勾：VS 起来又立刻死，**退出码 0**
`openInVisualStudio` 原来刻意 `env=nullptr` 继承父进程环境（注释还写着"UI 进程
要完整环境"）。但本机环境里有 `HTTP_PROXY/http_proxy`、`HTTPS_PROXY/https_proxy`
两组**只差大小写**的重复项 → VS 2022 的 ServiceHub 用大小写敏感字典装环境，
抛 `ArgumentException: 已添加项. 字典中的关键字:"HTTPS_PROXY"`，主窗口建完立刻
销毁，`GAMECODE opened devenv` 却已经打出来了（CreateProcess 确实成功）。
证据：`%APPDATA%\Microsoft\VisualStudio\17.0_*\ActivityLog.xml`（`/log` 启动）。
→ 改用现成的 `buildDedupEnvBlock()` + `CREATE_UNICODE_ENVIRONMENT`。
对照实验（ctypes）：同一份去重块启动 devenv 稳定存活；不去重则秒退。
