## ⚠⚠ 本轮踩的坑（都是"判据/夹具"，不是引擎）

1. **弧长均匀性判据不能用折线 + 自动手柄**：Catmull-Rom 在折点外插出"过冲回头"，
   回头处即使参数化完美，**位移**也只有弧长的一小截 → 两条判据一起红（arc=0.73）。
   换成**直线 + 手调手柄**（速度差 30 倍）才只剩"参数化"一个变量。
2. **`kArcSub=16` 不够**：速度差 30 倍时步内线性插值 t 会锯出 **10%** 的速度抖动
   （"弧长了但还是有点顿"）。→ 64 步，离散度 **10.3% → 0.48%**。
3. **锚点不能写在"点了才打"的分支里**：`if (!Button(...)) return; logRect(...)`
   人肉能用、自动化永远找不到（那是"界面点得到但测不到"）。必须无条件 logRect。
4. **面板内容比停靠后的窗口高**：滚出可视区的控件**矩形照样有**（logRect 不判可见性），
   照着点会点到别处 → 用例必须先滚（`scroll_into_view`）。
5. **`count_line("CINE-VERB")` 会把锚点行 `CINE-VERB-PAN=(...)` 也数进去** →
   计数要带后缀（`"CINE-VERB action="`），否则"有没有反应"这条判据永远成立。
6. **`CINE-STATE` 里的 `fov` 是残留值**（装了定焦镜头后被 focal 覆盖）→ 另打
   `fovEff`，判"焦距优先"要判 fovEff。
7. 编辑器视口相机**没有**每帧被 orbit 状态覆盖（`applyEditorCameraMode` 只设 flags），
   所以面板写 `setYaw/setPosition` 是生效的；但 **roll 必须单独 `setRoll`**
   （setYaw/setPitch 不同步它）。

## 脚本能力评估（回答"脚本是不是一片空白"）→ `docs/script_language_assessment.md`

**结论：不是空白，是"语言够、手不够长"。** 全部实测，没引旧数字。

- 存量：`engine/script/` **6861 行**；`.vks` 自研树遍历 VM；**84 个内建**（`kBuiltins[]` 表长，
  数学 17）；`--selftest script` **93/0**；4 个示例脚本（巡逻兵/定时门/拾取物/HUD）；S0~S6 全落地
  （`let`/`vec3`/`entity`/`list`/`foreach`/`on` 五钩子/`wait` 协程/热重载按 `Stmt::id` 对账）。
- **真缺口 1（致命）：组件覆盖 6/42 = 14%**。直连只有 Transform / Visibility / Point+SpotLight /
  Material(仅 emissive) / ScriptVars(脚本私有黑板)。**`CameraComponent` 29 字段可达 0 个**
  —— 刚做完的运镜体系脚本一条都改不了。另有 27 个组件零绑定（ParticleEmitter / Collision /
  PhysicsMaterial / DirectionalLight / Terrain / Water / Decal / ReflectionProbe …）。
- **真缺口 2（高）：写起来不顺** —— 无内联编辑器（改一行要切 VSCode）、无断点/单步/调用栈
  （grep `breakpoint` 零命中）、Instances 只显示变量**个数**不显示内容、面板内无 84 函数的参考。
- ⚠ **静默失败**：`setIntensity` 对没有灯的实体**返回 0 不报错** → 只有 `DirectionalLight` 的实体上
  写 `setIntensity(2.0)` 会"成功"但毫无反应，和"脚本没跑"长得一样。

**方案：白名单字段投影层**（不换 Lua）。路线 A 胜出，B/C/D 逐条算了账：
- B 换 Lua：三条退出条件（函数定义+3 关卡 / 要调试器 / 要生态）**零满足**；且换了不解决缺口 1。
- C 节点图：成本高于 S0~S6 总和；**只能在投影层之后**当第二套前端（编译到同一份 AST）。
- D C++ 热重载 DLL：崩溃即编辑器全挂，与熔断纪律正面冲突。

**投影层为什么不算推翻 S-D5**：S-D5 反对的是"任何组件任何字段"的无白名单反射；投影表是
**有白名单的**——表里没有的字段脚本**编译期就写不出来**（不是运行期拒绝），结构性封闭继续成立。
形态 `prop(e,"camera.focal")` / `setProp(e,"camera.focal",85)`，字段名走 `findBuiltin` 同一条
**编译期**解析路径（写成运行期字符串比较 = 把 P5 从函数名扩散到字段名，是退步）。
C++ 侧一张 `PropField{name,type,offset,lo,hi}` 表；用 `offsetof` 的代价必须写下来：
