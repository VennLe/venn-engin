## #144 · D1 语音「播完再进下一句」✅（30 条端到端 + 自检 141/0）

**缺口原文**（`docs/remaining_work_2026-10-27.md` §2.4）：`startVoice` 有句柄但
**无「播完了」查询** → 卡住 C2 语音版。

### 引擎侧
- `MixStats::busVoices[kBusCount]` + `Mixer::activeVoicesOnBus(bus)`。
  ⚠ **必须按总线**：只给全局 `voices` 的话后台循环音乐会让「这句播完了吗」永远为真。
  ⚠ `std::atomic<int> arr[N]` 在 C++17 **不初始化** → 构造函数体里逐个 `store(0)`
  （否则 `voicePlaying()` 读到栈垃圾，随机为真）。
- `AudioSystem::playVoice / voicePlaying / voiceSerial`。
  ⚠ **120 ms 宽限期**（`kVoiceGraceMs`）：`playVoice` 之后约一个 mix block 内音频线程
  还没标 active，直接查得 0 → 宿主第一帧就判"播完"。

### 对话侧
- `DlgNode::voice`（解析 + 写回；**空串不写盘**，老资产不长出 `"voice": ""`）。
- `Press::WaitingVoice` + `VoiceHooks{play, playing}` + `beginNodeVoice()`。
- 门的位置是硬约束：**补完打字机之后、翻页之前**（放前面=锁键盘，放后面=两句叠音）。
- 超时 `max(3.0, 字数×0.35)`，`m_voiceWait` 用 `std::min` **硬钳**上限
  （软钳会冲过上限一个 dt，日志打成 `7.10/7.00`，对拍用例只能猜）。
- 起播失败 / 钩子不装 → **不设门**（无声卡机器上每句白等 3 秒才是灾难）。

### 接线
- `DialogueSystem::setVoiceHooks()`：当场装 `m_cue`，组件播放器在 `tick()` 里按
  `hookGen()` **代数判等**对齐（`std::function` 每帧拷贝会分配，400fps×N 白烧）。
  ⚠ 装钩子必须在 `autoStart` **之前** —— `start()` 里就 `beginNodeVoice()` 起播第一句。
- `RuntimeApp::onInit` 在 `m_audio.init` 之后注入；`onShutdown` **必须摘掉**

   **first_level 复跑 12/12 PASS**（证明真的没丢字段）。
5. **词典涨了、图集装不下（1 条，`verify_ui2` 3 项）**：`ZhTable` 增到
   1289 字 → SDF 图集在 2048² 处溢出（97.6%）。`gen_sdf_atlas.py` 原来
   **默认正方形**，那段注释还写着"1059 字时装不下"—— 早就该自动长高。
   → `--atlas-h` 省略时**自动翻倍重排**；重生成 1289 字形后 `verify_ui2` PASS。

另外两条顺带修的：`verify_quality_presets` 把 `enable=22/keys=25` 写死
（引擎实测 24/27）→ 改成**拿自检报的 enable 数当尺子**（两条路径互相校验）；
`run_regression --explain` 拿 `Editor.exe` 当尺子判"没重建"，而**着色器不参与
链接** → 改对比 `build/bin/shaders/*.spv`（否则"只改 .frag"永远假警报）。
