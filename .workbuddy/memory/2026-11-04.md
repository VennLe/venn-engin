## 视口选择方式：摘掉"选择"模式行 + Tab 径向菜单（用户第 7 轮需求）

用户原话：
> 「模式类型中的选择这项移除掉，然后当鼠标在视口范围中时，鼠标按下 tab 键
>   不动时可以打开一个圆盘选项，分别有普通选择，框选，套索选择，刷选，然后
>   鼠标移动到哪个区域对应的选项就直接切换到对应的选择方式。」

### 做了什么

- 新建 `editor/SelectionModes.{h,cpp}`：`SelectionMode`（Pick/Box/Lasso/Brush）
  + 名字 / id / 提示 / 四个矢量图标。
- `EditorContext`：加 `m_selectionMode`（默认 Pick）+ `setSelectionMode`，日志 `SELMODE <id>`。
- `ModeRail`：列表从 10 行降到 9 行（`kModeRailRows`，锚点仍是**枚举值** 1..9）；
  Select 下的参数区从"说明卡"换成**选择方式四行面板**（`SELMODE-ITEM <id>` 锚点），
  点任一行 = 回到选择常态 + 换手感。
- `ViewportPanel`：
  - `drawSelectionRadial()`：按住 Tab → 四扇区饼；内圈 38px 死区；移动即切；松手关闭。
  - 三套手势：Box（起点在物体上也起框）、Lasso（松手闭合，屏幕矩形中心在多边形内）、
    Brush（26px 圆扫过，实时累加并 merge 到选择集）。
  - 抽出 `entityScreenRect()` 给三种手势共用（原来 `entityInsideBox` 内联的八角投影）。

### 修掉的既有 bug

**结算时"跳过已选中的"会让选择全丢**：`selectMany` 是替换语义，先滤掉已选中
等于把 `found` 弄空，然后走 `else clearSelection()`。表现是"连着框同一片区域
两次，第二次选中全没了"；套索更明显（先框 96 个再套同一片 → `LASSO-SELECT n=0`，
是自动化抓到的）。框选与套索两处都改了：`found` 只回答"这次命中了谁"。

### 视觉返工（两轮截图）

- 第一版扇区文字用长名 + 默认字号 → "Lasso Select / Brush Select / Box Select"
  糊成一条；中心还写了当前模式名，和上扇区重影。
- 改：字号 `0.82`（`AddText(font,size,...)`）、中心只画图标、扇区间缝画"深 2.6px +
  浅 1.0px"两条（单条深色在天空上会和阴影糊在一起）。
- 想用短名（Box/Lasso/Brush）被拦下：词表里 `Box`="盒"、`Brush`="笔刷"，是别的意思。

## 第二轮：选择方式列表搬到工具条 + 只选"物体"

用户原话：
> 「1.引擎编辑器中左侧的选择方式列表不需要移除掉吧，这个选择方式列表可以放在视口顶部
>   左侧的选择图标那里，点击箭头选择图标的时候展开这个方式列表。
>   2.所有的选择类型只能对场景中天空地面云层星空之外的物体对象操作生效」

### 1) 列表搬家（左栏 → 视口工具条左上那颗箭头）

- `ViewportPanel::drawToolMenu` 顶部加 `SeparatorText(TR("Selection Mode"))` + 四行单选
  （`vpSelModeRow`，与 `vpToolRow` 同一套排版：圆点 + 图标 + 名字 + 右侧 `Tab`）。
  **不受搜索框过滤** —— 搜索框只服务 Transform tools 那张表，四行固定项跟着消失像坏了。
- 工具条 ① 那颗按钮的图标在 `GizmoMode::Select` 时**画当前选择方式**（箭头/虚线框/套索/刷子），
  Move/Rotate/Scale 时照旧画手柄图标。
- `ModeRail` 里那四行删掉，换回一张说明卡（指向工具条箭头 + Tab 圆盘）。
  ⚠ 别再往左栏加第二份单选：两处各一份，用户改了一边另一边圆点不亮 = "没切过去"。
- 锚点沿用 `SELMODE-ITEM <id>`（现在在下拉弹层里），新增 `VP-SELMODE <id>` 日志。

### 2) 只对"物体"生效

- `editor::isSelectableObject(world, e)`（`SelectionModes.h`）= 有 Transform 且非 `LockedComponent`。
  点选（`PickingSystem`）/ 框选 / 套索 / 刷选四条路径共用这一条。
- 天空 / 云层 / 星空**不是实体**（`SkyParams` 程序化绘制），没有句柄 → 天然选不中；
  `verify_selection_modes` 新增 C6：在视口最上面的天空带拖框，`BOX-SELECT n=0`。
- ⚠⚠ **真凶是模板 Ground 漏了 `locked`**：`resetToEmptyScene()` 加，从 JSON 载入的不加 →
  框选一次就把整块地面带进选择集。已给 `templates/{third_person,first_person,isometric}/main.json`
  与 `assets/scenes/{anime_town,water_bowl}.json` 的 Ground/Terrain 补 `"locked": true`。
  这是**数据修复**，老工程不会自动变（层级里点 🔒 即可）。
- `MultiSelectSelfTest` 新增 G 组 5 条：普通可选 / 锁定不可选 / 解锁又可选 / 无 Transform 不可选 / 空句柄不可选。

### 3) 顺手修掉的两个既有问题

- **工具条右组放不下第 7 颗时**（`take[]` 按重要性截断），`VP-SPEED` 会**保留上一次的矩形**
  （`logRect` 只去重不判可见性）→ 自动化照着点，命中现在压在那儿的"视口设置"，
  弹出别人的菜单 → `V3a → V1 → V2a` 连锁全红。现在 `VP-BAR-FIT taken=n/7` **无条件**打，
  `verify_viewport_bar` 读到 `taken<7` 就 SKIP 那一条。
- **合成鼠标起手没预热** → 表现为"分组轮流红"（这次 R 组、上次 V 组，每次不一样）。
  `verify_viewport_bar.click` 补了两次 `SetCursorPos` + 0.3s。
